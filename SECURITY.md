# Security

## Reporting a problem

If you think you've found a security problem in RootTransfer, please report it **privately**:
go to **[Security → Report a vulnerability](../../security/advisories/new)** on this page.
Please don't open a public issue or post it elsewhere first.

Helpful to include:
- the RootTransfer version (shown at the bottom of Settings) and the device (Windows or Android, and its version)
- what someone could do with the problem, and the steps to show it

You'll get an answer within a week. Please allow up to 90 days for a fix before you publish anything. Reports are credited in the release notes, unless you'd rather not be named.

## Which versions get fixes

Only the newest version. RootTransfer tells people on its home screen when a new version is out, so please check with the newest version before reporting.

## What counts

For example: reading or changing someone's files, saving files without the person pressing Accept, pretending to be another device, taking over an address, or getting RootTransfer to run a program or send files it shouldn't.

Not security problems: someone sending you unwanted offers (use Block, "Only accept files from people I know", or Pause receiving), and Windows' "unknown app" warning (the installer isn't signed yet).

# Drošība (latviski)

Ja domājat, ka esat atradis drošības problēmu RootTransfer, lūdzu, ziņojiet par to **privāti**: šajā lapā atveriet **[Security → Report a vulnerability](../../security/advisories/new)**. Lūdzu, vispirms neveidojiet publisku "issue" un nepublicējiet to citur.

Atbilde būs nedēļas laikā. Lūdzu, dodiet līdz 90 dienām problēmas novēršanai, pirms kaut ko publicējat. Labojumi tiek veikti tikai jaunākajai versijai.
